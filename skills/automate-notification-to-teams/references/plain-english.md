# Voice Align writing rules

Apply these rules to all plugin text. They follow the writing standard in Voice Align.

- Start with the first useful point.
- Use common words and complete sentences.
- Keep one idea in each sentence.
- Use one clause per sentence unless splitting it changes the meaning.
- Preserve facts, product names, labels, commands, and identifiers.
- Explain required technical terms when they first appear.
- Use the full term unless a shortened form identifies a product or field.
- Correct spelling and grammar.
- Remove filler, metaphors, em dashes, repeated facts, and closing summaries.
- Use short questions that the user can answer without technical knowledge.
- Use numbered bullets when order matters.
- State an unknown fact as unknown.
- Describe only the result supported by the evidence.

For an automation explanation, use Trigger, Inputs, What happens, and Outputs. State every action and condition in order.

If the user invokes Voice Align, also follow that skill's delivery instructions for the current run. Do not copy private delivery identifiers into this plugin.
